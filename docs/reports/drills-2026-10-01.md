## As found

**The card said nothing when a wallpaper's files had gone.** Found by the delete-a-playing-folder drill. `nowPlaying` built the card's status from the pause reason alone, so a display holding the neutral colour for a missing file read as playing. It now asks whether the shown wallpaper's optimised copy is in the library when the card is read (no poll) and says "Files missing" before any pause; test-first in `NowPlayingTests`. Re-run on the fixed build: the card reads "Files missing".

**The worktree's build had no ffmpeg and no shader tools.** Found by the cut-source drill, whose first run failed with `helperMissing`. `Helpers/ffmpeg/out` and `Helpers/shader-tools/out` are ignored by git, so a fresh worktree builds without them, as `project.yml` says it will. Copied in, rebuilt, and the drill run again. Not a product change.

**A second launch of a freshly registered bundle took the extension down.** After the drill's swap the old app process kept running; quitting it and opening the new bundle re-registered the extension, which ended it, and the 600 s rule held the agent restart for nine minutes. That is the install hazard M5 recorded, met by two installs inside ten minutes; the rule is a record's and stays.
