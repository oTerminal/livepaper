## S9: Wallpaper Engine scenes read and drawn with Metal

Run 2026-09-23, macOS 27.0 (26A428), Apple M5, Xcode 27 toolchain (Swift 6 language mode, tools version 6.0).
Code: `Spikes/S9/`, a standalone SwiftPM package. Samples: the seven scene items in `we-samples/`
(1195626192 Gaze, 1851524277 A Lonely Winter, 1877443413 Jet Lag, 2688873830 Backstreet Lofi,
2987840102 Botanical, 3289988463 Lonely Cat, 3775394622 Agamemnon). They are other people's work, so no
file, render or translated shader of theirs is in the repo; the renders are in the session scratchpad (below).

Every claim is marked **(measured)**: run and checked, or looked at; or **(inferred)**: read off the sample
files or reasoned, not checked against Wallpaper Engine, which is not on this Mac.

Step 4 (GPU cost) was dropped at the user's request, midway, in favour of drawing more of the scenes
correctly. There are no timings here; an early timing run was discarded.

### Verdict

Feasible. All seven scenes read without a parse failure, all 42 shader programs they draw with translate
to MSL, compile and link, and all seven draw every frame from scene time, close to their previews. What
still differs is known and listed under "What remains" **(measured)**. The hardest pieces are not the
renderer: they are the things items do not carry. Wallpaper Engine's stock particle textures, its base
shaders and headers, and the meaning of undocumented parameters (blend-mode numbering, particle operators)
all have to be supplied or guessed.

### Layout of the package

| Target | What |
|---|---|
| `SceneItemFormat` | `.pkg`, `.tex`, `.mdl` puppets, and the scene / model / material / effect / particle JSON. No Metal. |
| `SceneShaderTranslation` | Workshop GLSL → MSL (glslang, SPIRV-Cross), with our `common*.h` in `Resources/include`. |
| `SceneImport` | Import time: every program a scene draws with (`ProgramRequest.all`), translated into a `ProgramManifest` (`scene-programs.json`) beside the item's files. Our base materials (`genericimage*`, `genericparticle`) in `Resources/materials`. |
| `SceneItemRenderer` | Load and draw. `SceneRenderer(folder:device:)`, `resize(width:height:)`, `draw(into:on:at:)`: the shape of LivepaperScene's `SceneDrawing`. It encodes into the caller's command buffer and texture (any colour format), never commits, waits or owns a queue, and never runs the translator. |
| `s9` | The command line: `inventory`, `translate`, `sweep`, `import`, `render`. |

`render` does what the product would do: it clones the item's `project.json`, `.pkg` and preview into a
library folder, runs `SceneImporter.prepare` (which writes the manifest there), loads
`SceneRenderer(folder:device:)` from that folder, and draws 30 frames a second into a BGRA texture.
To run it: `brew install glslang spirv-cross`, then in `Spikes/S9` `swift build -c release` and
`.build/release/s9 render <item folder> <output folder> [WxH] [seconds] [noparticles] [noeffects]`.

### 1. Reader

Everything in all seven packages parses: 134 JSON files, 50 textures (mip 0 of every image decoded, except
the one MP4), one puppet **(measured, `s9 inventory`)**. What the samples showed beyond
what was already known:

- **`.tex` container versions.** `TEXB0002` (Gaze) has no free-image field; `TEXB0003` adds it; `TEXB0004`
  (Agamemnon) adds one more i32 after it, 0 in every sample **(measured)**.
- **Formats.** 0 RGBA8888, **8 RG88** (a normal map), **9 R8** (masks, a depth map). Embedded images:
  free-image format **2 JPEG, 13 PNG**, whose mip 0 is the image's own size, not the padded texture size
  **(measured)**. No DXT/BC texture in any sample, so their format codes are unknown **(measured)**.
- **Flags** **(inferred)**: 0x1 point filtering (the GIF template's "point filter"), 0x2 clamp (masks and
  images; the tiling normal maps have 0), 0x4 animated, **0x20 the payload is an MP4** (Backstreet's
  "Arnold" texture: the mip bytes start `ftypisom`; H.264, not decoded by S9), 0x100000 unknown (one mask).
- **Sprite sheets.** `TEXS0003`: frame count, frame width, height, then 32 bytes per frame: i32 image,
  f32 seconds, f32 x, y, then the frame's two axes (width, 0) and (0, height). Botanical's 40 frames span
  **two images** of 7680×7560 (28 + 12 frames) **(measured)**.
- **Puppet `.mdl`** (Agamemnon, `MDLV0023`). Read from the file alone **(measured on the one sample)**:
  1277 vertices of 80 bytes (position, normal, tangent, four bone indices, four weights, UV), 2405 triangles
  as u16 indices in six parts, an `MDLS0004` skeleton (6 bones: parent and a local bind matrix each, then
  per-bone data S9 does not need), and an `MDLA0006` animation ("Animation 1", mode "mirror", 60 frames at
  12 fps; per bone per frame position, angles, scale). The layout is written out in `PuppetModel.swift`.
  In the bind pose the mesh is the texture's own layout; the animation moves the ponytail onto the helmet.
- **Scene JSON.** Values come plain, as "x y z" strings, or wrapped: `{"value", "user"}` (a user
  property), `{"value", "script"}`, `{"value", "animation"}`. Old items key `constantshadervalues` by the UI
  label (Gaze), new ones by the material name, and each item's own shader copy matches its keys **(measured)**.
  Scene passes line up with an effect's material passes, skipping `copy` commands **(measured)**.
- **Not in the items.** Particle textures (`particle/halo`, `particle/fog/fog1`, …, in 5 scenes), `util/*`
  textures (`white`, `black`, `noise`, `clouds_256`, `noflow`), the base shaders `genericimage`,
  `genericimage2`, `genericimage4`, `genericparticle`, and the headers `common.h`, `common_blending.h`,
  `common_blur.h`, `common_perspective.h` **(measured)**. Correction to the brief: `godrays_downsample2` and
  `godrays_gaussian` are in Backstreet Lofi's package; `common.hlsli` appears only in a commented-out include.
  Also built in, not in items: `models/util/fullscreenlayer.json`, `composelayer.json`, `solidlayer.json`.

### 2. Shader translation

Route: prepend the combo `#define`s and our `common.h`; glslang's preprocessor resolves `#include`
against our headers; a rewrite turns the GLSL 1.x declarations into Vulkan GLSL 4.50 (`attribute` →
`in` at fixed locations, `varying` → matching locations by name across the stages, loose uniforms → one
std140 block, samplers → `binding = slot`); glslang → SPIR-V; SPIRV-Cross → MSL 2.4 with the SPIR-V bindings;
`makeLibrary(source:)` at load. The uniform annotations give each uniform's material key and default; the
`[COMBO]` lines give combo defaults; a sampler's `"combo"` switches its combo on when a texture is bound.
It fits: nothing needed hand-editing per shader **(measured)**.

What the dialect expects of the missing headers, all written from scratch from how the shaders use them
**(inferred; each produces the expected picture where it could be seen, measured)**: HLSL spellings as macros
(`texSample2D`, `frac`, `saturate`, `lerp`, `atan2`, `CAST2/3/4`, `CAST3X3`); `mul(v, M)` as a row vector
times a matrix, so `M * v` with our column-major matrices; `rotateVec2`, `greyscale`, `rgb2hsv`, `hsv2rgb`;
`M_PI_2` is a **full turn** (Simple_Audio_Bars divides `atan2 + π` by it to get 0..1); `blur13a/7a/3a(uv, step)`
take no texture and are sometimes used before `g_Texture0` is declared, so they are macros; `squareToQuad`
is the square-to-quadrilateral homography; `ApplyBlending(mode, a, b, opacity)`.

PERSPECTIVE=1 through `squareToQuad`, each kernel, …), with texture-switched combos on and off: 244 of 244
**(measured, `s9 sweep`)**.

The first run translated 31 of 39. The eight failures and what fixed them **(measured)**:

| Failures | Cause | Fix |
|---|---|---|
| filmgrain, Simple_Audio_Bars: `BLENDMODE` undeclared | CRLF files: Swift treats `\r\n` as one character, so the reader split nothing and missed every `[COMBO]` line. A bug in S9, not the dialect. | split on `isNewline` |
| pulse (3 variants), godrays_downsample2, godrays_cast: `unexpected SAMPLE` | `sample` is a reserved word in GLSL 4; they use it as a variable | `#define sample lpSample` in `common.h` |
| shift_hue: `rgb2hsv` not found, then `mix(vec4, vec3, float)` | expects `rgb2hsv`/`hsv2rgb` from `common.h`; and an HLSL-ism, a silent vec4→vec3 truncation | the two functions, and a `vec3 mix(vec4, vec3, float)` overload (glslang accepts overloads of built-ins) |

The truncation is the risk in the route **(inferred)**. The dialect is compiled to HLSL on Windows: the
`.dxs` blobs beside some packages hold DXBC bytecode in a `blobsSM40` folder, and `CAST2` exists because
HLSL has no one-scalar vector constructor. So authors only ever test HLSL semantics. Function-argument
cases can be patched with overloads; an assignment such as `vec3 c = someVec4;` cannot. Alternatives, if a
larger corpus shows many: glslang's own HLSL front end after mapping the GLSL spellings to HLSL (same two
libraries, HLSL's implicit conversions); DXC → DXIL → Apple's Metal Shader Converter (a third toolchain); a
hand-written GLSL→MSL rewriter (fragile).

Manifests written at import: 5 KB (Botanical, 1 program) to 219 KB (Backstreet Lofi, 27 programs), no
failures **(measured)**.

### 3. Renderer

What it does, and the semantics it assumes **(inferred unless marked)**:

- **Scene space.** `orthogonalprojection` units, y up, origin bottom left (the islands of A Lonely Winter land
  where the preview has them, **measured**). The output is covered, centred, cropping the longer axis. Objects
  are drawn in the scene's order: translate to `origin`, rotate by `angles.z`, scale `size × scale`.
- **Image layers.** Our `genericimage` draws the texture, the current sprite-sheet frame, or a puppet mesh.
  `g_TextureNResolution` is (texture width, height, image width, height): the masks' UV maths only works so
  (**measured** by the masks lining up).
- **Effects.** A layer with effects is drawn into its own target at the size it covers on screen; each effect
  pass draws a clip-space quad (MVP identity: the horizontal blur ignores the MVP, which only works if it is
  identity) into ping-pong targets. `fbos` (with a size divisor), `bind` ("previous" or a named target),
  `copy`, `_rt_FullFrameBuffer`, `_rt_imageLayerComposite_<id>_a`, and suffixed unique names
  (`_rt_FullCompoBuffer1_61_69`) all resolve. Targets persist, so motion blur accumulates. Samplers with a
  declared default get it (`util/white`, `util/noflow`). `fullscreenlayer` runs effects over the frame so far,
  `composelayer` over what is behind its rectangle, `solidlayer` is a flat colour.
- **Blending.** "normal" replaces, "translucent" is source-alpha over, "additive" adds. `ApplyBlending`'s mode
  numbers are a guess: Photoshop's menu order without Dissolve fits every default the samples declare
  (blend 2 multiply, pulse and godrays 9 linear dodge, film grain 12 soft light).
- **Bloom** (`general.bloom`, Backstreet and Agamemnon): bright pass at quarter size over the threshold,
  blurred twice each way, added at the strength. Our own passes, in plain MSL.
- **Puppet.** Linear skinning in our `genericimage` (`SKINNING`, up to 32 bones), animation sampled linearly,
  "mirror" played back and forth. Parts are drawn in file order: sorting them by their ids put the ponytail
  under the helmet (**measured**).
- **Particles.** A first system on the CPU: sphere and box emitters; lifetime, size, colour, alpha, velocity,
  turbulent velocity, rotation and angular velocity initialisers; movement (gravity, drag), alpha fade and
  change, size change, alpha and position oscillation, turbulence, angular movement, control-point attraction;
  sprite, sprite trail and rope trail (drawn as a trail); children beside the parent and "eventspawn" bursts
  where parents die; `starttime` warm-up; `instanceoverride` (count, rate, size, alpha, lifetime, speed,
  colour). Every parameter's meaning is read off the preset values. Textures are procedural stand-ins
  (soft dot, noisy blob for fog and smoke, a beam for light shafts).
- **Not done:** sound (not played), audio-reactive uniforms (fed silence), pointer parallax and
  `depthparallax`'s pointer (centre), scripts, the MP4 texture (on a layer hidden by default), the scene
  camera's `center`/`eye` offsets (ignored).

a 5 s MP4 at 30 fps, all through import → library folder → load → `draw` **(measured)**:

### 5. What remains

- **Texture formats**: an MP4 texture decoder (AVFoundation into a texture); BC/DXT once an item shows the
  codes (Metal decodes BC on Apple silicon). Small.
- **Image layers and the effect graph**: done for these samples. Left: confirming the blend-mode numbering,
  the pass flag `compose`, FBO formats (`rgba_backbuffer`), `colorBlendMode`, the camera offsets, user
  properties (which layers show, e.g. Backstreet's "screen"). Small to medium; needs a larger corpus.
- **Shader translation**: works on all 42 and 244 variants. Left: linking glslang and SPIRV-Cross into the
  app for import (or shipping them as a helper, like ffmpeg), a larger corpus to find more HLSL-isms, a
  pipeline cache (`MTLBinaryArchive`). Medium, mostly the corpus.
- **Particles**: a system exists. Left: our own particle texture set (the items reference Wallpaper Engine's),
  animated particle sheets (`animationmode`, `sequencemultiplier`), exact operator semantics, perspective rain.
  The largest remaining piece, and the most visible.
- **Puppet warp**: works on the one sample. Left: other MDL versions, several animations, the per-bone
  data S9 skips. Needs more samples.
- **Sound**: playing the mp3s. Small.
- **Audio-reactive**: capturing system audio (a Core Audio tap or ScreenCaptureKit, with permission) and
  16/32/64-band spectra. Medium, plus a privacy decision.
- **Parallax**: needs the pointer, which a wallpaper extension may not get. Unknown.
- **Scripts**: skipped (JavaScript per property). Decide whether to take the stored values only, as S9 does.

### Open questions

1. Is the blend-mode numbering right? One Wallpaper Engine scene using each mode, rendered by the real thing,
   would settle it.
2. What does an effect pass's `"compose": true` do (blurprecise's first pass)?
3. Should the scene camera's `center`/`eye` offset shift the view (Gaze, Jet Lag set one)?
4. At what resolution does Wallpaper Engine run a layer's effects: texture size or screen size? It changes
   pixel-scale effects (blur radius, grain).
5. Particle textures: draw our own set, or leave particles out? Items cannot supply them.
6. Audio-reactive scenes: is capturing system audio acceptable for a wallpaper?
7. Where import runs the translator: glslang and SPIRV-Cross linked into the app, or a helper tool.
